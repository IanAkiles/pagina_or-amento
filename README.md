# Página de orçamento

Site estático para apresentar serviços de desenvolvimento web e montar uma mensagem de orçamento para enviar pelo WhatsApp.

Para visualizar, abra [`index.html`](index.html) no navegador com a pasta [`assets/`](assets/) ao lado. Consulte o [guia de publicação](leia-me-deploy.txt) para instruções de hospedagem e a observação sobre a licença da fonte.
